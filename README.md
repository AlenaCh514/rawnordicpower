# Raw Nordic Power — сайт (инструкция)

## Что здесь лежит
- `index.html` — сам сайт (главная страница).
- `songs.js` — список песен. Это единственный файл, который нужно править, чтобы добавить песню.
- `audio/` — MP3 и WAV файлы песен. Кнопки скачивания ведут сюда.
- `assets/logo.png` — логотип сайта.

## Как посмотреть сайт у себя на компьютере
Открой файл `index.html` двойным кликом — он откроется в браузере. Всё работает без интернета, кроме ссылки на YouTube.

## Как добавить новую песню самой
1. Положи MP3 файл песни в папку `audio/`.
   Например: `audio/never-give-up.mp3`
   WAV пока не нужен — кнопка WAV сама появится, только если добавишь WAV-файл и укажешь его в songs.js.
2. Открой файл `songs.js` в любом текстовом редакторе (Блокнот, Notepad).
3. Найди блок первой песни (от `{` до `},`) и скопируй его целиком.
4. Вставь скопированный блок после него, перед строкой `];`
5. В новом блоке поменяй:
   - `id`: короткое имя латиницей без пробелов (например `"never-give-up"`)
   - `title`: название песни
   - `mp3`: `"audio/never-give-up.mp3"` (или `""`, если файла пока нет)
   - `wav`: `"audio/never-give-up.wav"` (или `""` — тогда кнопки WAV не будет; появится сама, когда добавишь файл)
   - `video`: ссылка на клип на YouTube (или `""`, если пока нет)
   - `lyrics`: текст песни между знаками ` (обратные кавычки)
6. Сохрани файл. Песня сама появится на сайте: на главной, в скачивании и в текстах.

## Как устроены связки
- Вкладки сверху: Songs, Albums, About. Внизу — только логотип и подпись, больше ничего.
- Songs: список песен мелким шрифтом — номер, название, точечки, кнопка Lyrics. Клик по Lyrics показывает текст песни, видео и поддержку; «← All songs» возвращает к списку.
- Albums: пока пусто — альбомы появятся, когда выйдут на DistroKid.
- About: рассказ о проекте.
- Поиск сверху списка песен прячет неподходящие песни.
- Ссылки магазинов берутся из списка LINKS в начале songs.js; пустая ссылка — кнопка не показывается.
- MP3-файл песни лежит в папке audio/, но на сайте не предлагается к скачиванию.
- Кнопка «Support the Artist» пока без ссылки — она заработает, когда будет ссылка для донатов.

## Что ещё нужно сделать
- Прислать ссылки на свои страницы артиста в Spotify, Apple Music и Amazon — вставить их в LINKS в начале songs.js, кнопки появятся сами.
- Дать ссылку для донатов (кнопка Support the Artist).
- Выложить эти файлы на бесплатный хостинг GitHub Pages и направить домен rawnordicpower.com на него (две строчки в Porkbun).
